# Contributing to Clarity

Thanks for helping improve Clarity — a student mental-wellbeing platform built for Smart India Hackathon 2025.

## How to contribute

1. Fork the repo and create a branch from `main` (`git checkout -b fix/short-description` or `feature/short-description`).
2. Make one focused change per pull request. Keep the diff small and describe what it fixes.
3. Follow the setup in the README: `npm install`, then `npm run dev` to check your change locally and `npm run build` before opening the PR.
4. If you change behaviour, say how you tested it in the PR description.
5. Open the PR against `main` with a clear title and a short summary of the change.

## What we welcome

- Bug fixes and small UX improvements
- Accessibility fixes
- Documentation corrections
- New wellness resources or content, with a source

## Please don't

- Open PRs that reformat unrelated files or restyle the whole codebase.
- Add new dependencies without explaining why in the PR.
- Share real user data, credentials, or API keys in issues or PRs. Use placeholders.

## Reporting a bug

Open an issue with: what you did, what you expected, what happened instead, and (if you can) a screenshot. The live demo is at https://adityaxdeore.github.io/Clarity-Mental-Health-AI-assistance/
